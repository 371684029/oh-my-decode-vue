# 低代码前端可视化平台 (Low-Code Studio) - v1.2.0 多图层架构与自定义 HTML 生命周期规划

> **版本定位**：多图层系统 (Multi-Layer System) & 自定义 HTML / 节点生命周期脚本 (Lifecycle Hooks)
> **状态**：进行中 (In Progress)
> **前置版本**：v1.1.0 (体验增强版)

---

## 🎯 1.2.0 核心目标

在低代码搭建中，随着页面业务逻辑变复杂，单一画板已无法满足弹窗 (Dialog/Modal)、全局加载遮罩 (Loading Mask) 以及自定义原生 HTML/JS 组件的需求。

v1.2.0 引入**多图层管理架构 (Multi-Layer Architecture)** 与 **自定义 HTML 生命周期系统 (Custom HTML & Lifecycle System)**：

1. **多图层解耦与叠加管理 (Layer Types)**：
   - **基础画布图层 (Canvas Base Layer)**：默认主页面画布。
   - **对话框/弹窗图层 (Dialog Overlay Layer)**：独立弹窗图层，可在该图层内拖拽放置表单/表格组件。
   - **全局 Loading 加载框图层 (Loading Mask Layer)**：遮罩与提示词图层，支持动态控制显隐。
   - **自定义 HTML 动态图层 (Custom HTML Layer)**：支持直接编写自定义 HTML 结构、CSS 样式与 Vue/JS 生命周期钩子。
2. **自定义 HTML 生命周期钩子 (Lifecycle Hooks)**：
   - 在自定义 HTML 图层中，支持独立配置：
     - `onMounted(container, state)`：挂载完成生命周期脚本。
     - `onUnmounted(container, state)`：卸载生命周期脚本（如清除定时器/事件监听器）。
     - `onUpdated(container, state)`：状态更新生命周期脚本。

## 📋 Schema 契约设计

在 `PageSchema` 中扩展 `layers` 数组：

```ts
export type LayerType = 'canvas' | 'dialog' | 'loading' | 'custom-html';

export interface LayerConfig {
  id: string;
  name: string;
  type: LayerType;
  visible: boolean; // 是否在渲染时/画布中可见
  zIndex: number;
  props?: {
    title?: string;
    width?: string;
    maskColor?: string;
    loadingText?: string;
    htmlCode?: string;
    cssCode?: string;
    scriptMounted?: string;
    scriptUnmounted?: string;
    scriptUpdated?: string;
  };
  children: ComponentNode[];
}
```
