## 🎯 1.0.0 正式版核心目标

经过 v0.0.1 至 v0.5.0 的快速迭代，平台已打通“**拖拽网格 -> 属性配置 -> 表达式绑定 -> JSON 存储/审计日志 -> 响应式多端预览 -> 多目标出码**”的全流程。

v1.0.0 作为正式落地版本 (GA)，**不再盲目扩展外部依赖或大厂复杂架构，而是“基于已有功能进行极致的打磨与细化”**，确保现有的每一项功能都达到**金融级的稳定性、极佳的操作手感与零白屏的容错能力**。

## 📋 现有 5 大核心模块的细化与完善方案

### 1. 画布拖拽与响应式布局的细化 (Canvas & Responsive Layout Refinements)
- **大纲图层树 (Component Layer Tree View)**：
  - 在左侧物料库旁增加“页面图层大纲树”，树形展示当前画布上的所有组件（包含嵌套容器及其子节点）。
  - 支持在大纲树中高亮选中、拖拽重排组件顺序、一键显示/隐藏节点、一键锁定节点（防止误拖拽）。
- **画布辅助参考线与吸附对齐 (Guides & Snapping)**：
  - 在拖拽与调整组件大小时，画布上显示水平/垂直中线吸附参考线与间距数值标尺。
- **键盘辅助精度微调**：
  - 选中画布节点时，支持方向键 (`↑` `↓` `←` `→`) 以 1px 或 1 个栅格单位进行位置微调。

### 2. 属性抽屉与动态表达式的细化 (Property Drawer & Expression System)
- **表达式输入高亮与语法提示 (Expression Helper with Code Mirror)**：
  - 在属性抽屉的表达式输入框（绑定 `{{ ... }}` 时）中提供代码高亮、括号匹配与语法正确性实时校验。
  - **实时求值预览助手**：在表达式输入框下方实时展示当前表达式在当前上下文中的计算求值结果（例如：`{{ formData.age >= 18 }}` -> 渲染为 `true`）。
- **组件 I/O 契约强校验交互升级**：
  - 基于 `docs/implemented/COMPONENT_IO_SPECIFICATION.md`，若必填参数未配置，属性抽屉顶部悬浮提示“⚠️ 剩余 1 项必填参数未配置”，且画布对应节点角标闪烁黄色警告框。

### 3. 多目标零废码出码引擎的细化 (Code Generator Enhancements)
- **出码依赖自动提取与 `package.json` 一键打包**：
  - 导出 Vue 3 SFC 代码时，出码引擎自动分析当前页面用到的物料（如 `element-plus`、`pinia`、`lucide-vue-next` 等），并在导出弹窗中附带可直接运行的 `package.json` 配置。
- **Prettier 代码自动美化**：
  - 在出码导出时，自动调用内嵌的轻量 Prettier 格式化代码，确保导出的 `.vue` 与 `.js` 缩进工整、符号规范、零多余空格。
- **独立 HTML 打包脚本优化**：
  - 导出的 standalone `.html` 静态包中，将内嵌 CSS/JS 注入压缩，提供一键“本地无服务端预览”体验。

### 4. 存储、自动保存与审计日志控制台的细化 (Storage & Audit Log Perfection)
- **JSON 文件原子写入与双重副本容错 (Atomic Write & Safety Backup)**：
  - 将后端 JSON 写入从普通的 `writeFile` 升级为 **原子写入 (Write to temp file -> Replace)**，防止保存中断造成 JSON 文件损坏。
  - 每次覆盖保存时，自动在 `storage/backups/` 留下上一次操作的影子副本 (`.bak`)，支持一键恢复上一次稳态保存。
- **日志控制台 JSON Diff 增量高亮**：
  - 在 SQLite 操作日志弹窗中，点击某条“修改 Schema”日志，弹窗右侧以绿/红高亮对比展示该次保存与前一次保存的 Schema 改动差异（JSON Patch Diff）。

### 5. 独立单页运行与预览入口 (Standalone Preview & Zero-Dependency Runtime)
- **独立运行预览路径 (`/preview/:pageId`)**：
  - 提供纯粹的纯预览页面，隐藏低代码编辑器设计器边框、顶部栏与物料库，仅渲染最终页面图层。
  - 支持一键复制 Preview URL，方便直接发送给产品经理或测试人员进行功能走查。

## 💡 v1.0.0 落地实施好建议 (Practical Best Practices)

1. **加装全局错误边界防护 (Vue Error Boundary Guard)**：
   - 在画布节点渲染外层封装 `<ErrorBoundary>` 组件。当用户通过动态表达式写错代码导致某个组件运行时报错时，仅该组件展示“⚠️ 组件渲染异常，请检查配置”降级 UI，**确保画布其他部分与设计器控制栏绝不崩溃白屏**。
2. **保持出码可读性高于一切 (Human-Readable Output)**：
   - 低代码平台的生命线是“出码质量”。确保导出的 Vue 代码如同优秀高级前端工程师手写一样干净，变量名规范（如 `formData`、`handleSubmit`），不包含任何低代码框架本身的私有 runtime 脏代码。
3. **极简运维，坚持单机免部署理念**：
   - 1.0.0 坚持 **Node.js + Express + SQLite + 本地 JSON** 架构，无需安装外部复杂数据库，双击 `npm run dev` 即可在任何 Windows/Mac/Linux 机器上启动。
