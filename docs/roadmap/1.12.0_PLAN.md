# 低代码前端可视化平台 (Low-Code Studio) - v1.12.0 语料库导出规划

> **版本定位**：把已经能出的 Vue 组件和 HTML 组件收成可复用的语料
> **状态**：已实现 (Implemented)。范围与验收见下文，实现已合入 v1.12.0
> **前置版本**：v1.11.0（出码与画布对齐）
> **平台定位约束**：纯前端搭建 + 出码，**不生成后端业务代码**

---

## 一、为什么做这一版

拖拽页面之后，导出对话框能分别下载 Vue 单文件组件和独立 HTML。每次只有当前这一种文件，不能把同一页同时留成两种组件，也不能把已保存的页面收成一份语料。

语料库是出码核心的下一层：一条页面产生两条记录，一条是 Vue 组件，一条是 HTML 组件。生成函数仍用现有的 `generateVueSFC` 和 `generateHTML`，不另写渲染器。

---

## 二、P0 — 一条页面，两种组件

**现状**：导出页签各自调用生成函数，下载单个 `Page.vue` 或 `index.html`。

**方案**：

- 语料记录包含 `id`、`title`、`kind`、`filename`、`source`。
- `kind` 为 `vue` 时，`source` 是 Vue 单文件组件，文件名以 `.vue` 结尾。
- `kind` 为 `html` 时，`source` 是独立 HTML，文件名以 `.html` 结尾。
- 同一页面 id 只保留一份 Schema。当前画布覆盖同 id 的已保存副本。
- 文本格式是 JSONL，一行一条记录。

**验收**：当前页导出的 JSONL 恰好两行，分别含 `"kind":"vue"` 和 `"kind":"html"`，源码分别是 `<template>` 与 `<!DOCTYPE html>`。

---

## 三、P0 — 导出入口

**现状**：导出对话框没有语料库页签。已保存列表只用于载入。

**方案**：

- 导出对话框增加「语料库」页签，可复制、可下载 `corpus.jsonl`。
- 默认只收当前画布，不请求后端。
- 勾选「包含已保存的页面」后读取 `GET /api/schemas?type=page`，与当前画布合并。后端不可用时保留当前页，并提示。

**验收**：打开导出并切到语料库，能看到 Vue 与 HTML 两种记录。勾选后，已保存且 id 不同的页面会多出对应两行。

## 六、范围边界（本版明确不做）

- 不把 Web Component 再单独做成第三种语料；HTML 组件用独立 HTML。
