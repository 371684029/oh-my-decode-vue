## 执行计划

### M1 — P1 收口（本轮）

1. **shortHash 移入 shared**：`@lowcode/shared` 导出 `shortHash`，前端 codegen/shared、materialPacker、后端 versionClassify 改为引用。
2. **收窄 `as any`**：为 `normalizeNodeIds` / `structuralSignature` 定义最小节点类型；`updateNodeLayout` 用 Grid 布局项类型。
3. **watch 优化**：拖拽/缩放手势期间跳过 stringify getter（用 `layoutGesture` 标志短路）。
4. **静默 catch 改进**：materialResolver 捕获后返回空数组时至少 console.warn；CodeExportDialog 捕获后提示用户。

### M2 — P2 测试补齐

5. jsonPatch 边界测试（根路径、非容器、add OOB、`/-`、空 ops、invert 错误）。
6. designerStore 黑盒路径测试（addBlackBoxFromMaterial / addMaterialSmart / setPageSchema / enterLayerEdit）。
7. materialController 集成测试（refs 409 / force / diff）。
8. pageUpgradeService / materialRefScan 单元测试。
9. StorageService 非保存路径测试。
