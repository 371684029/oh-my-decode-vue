# 低代码前端可视化平台 (Low-Code Studio) - v1.9.0 Mock 与接口文档规划

> **版本定位**：一键补上页面里还没填地址的表格和表单数据源，并写出前端实际会调用的接口说明
> **状态**：已实现 (Implemented)。范围与验收见下文，实现已合入 v1.9.0
> **前置版本**：v1.8.0（改名、删除、恢复、纯预览、下拉选项）
> **平台定位约束**：纯前端搭建 + 出码，**不生成后端业务代码**

---

## 一、为什么做这一版

拖进高端表格或高端表单之后，画布用占位数据，出码里的 `fetch` 却没有地址。属性抽屉可以手填 `apiBinding`，但要自己想路径、参数和响应形状。

v1.9.0 只做一件事：按页面里已经存在的表格、表单和已填写的数据源，一键补上 Mock，并给出前端请求这些接口时需要的说明。

---

## 二、P0 — 一键补 Mock，不覆盖已有地址

**现状**：`apiBinding` 缺省时表格显示占位行，表单为空。已填写的 `url` 会在设计器和出码里发真实请求。

**方案**：

- 头部按钮「生成 Mock 与接口文档」只处理 `pro-table` 和 `pro-form`（含嵌套子节点和非画布图层）。已经有 `url` 的绑定保持原样。
- 新绑定的地址是相对路径 `/api/mock/${节点 id}`。浏览器里的相对请求会打到设计器自己的页面，打不到后端，所以设计器在 `ApiExecutor` 里直接返回绑定上的 `example`，不发网络请求。
- `example` 写入 Schema，保存后重新打开仍然能返回同一份示例。出码只保留 `url` 和参数，不把示例嵌进生成的 JavaScript。导出的页面按该路径 `fetch`，Markdown 是给对接用的约定。
- 表格示例为 `{ data: { list, total } }`，`responsePath` 为 `data.list`，`totalProp` 为 `data.total`。列字段与占位行一致时使用同一批占位行，否则按列名生成两行。
- 表单示例为 `{ data: { 字段: 示例值 } }`，`responsePath` 为 `data`。
- 写入后记入撤销栈，并通知对应节点重新加载。再点一次不重复添加。

**验收**：空表格点一次后出现 `/api/mock/` 绑定，画布仍能看到占位姓名。已有真实 URL 的节点地址不变。撤销可以回到点击前。

---

## 三、P0 — 前端所需接口文档

**现状**：导出对话框只有 Vue、Web Component、HTML 和 package.json，没有接口说明。

**方案**：

- 文档覆盖页面上每一个带 `url` 的数据源，包括这次新加的 Mock 和原来就有的地址。
- 每条写出方法、路径、参数、列表路径、总数字段和响应示例。
- 一键操作后弹出对话框，可复制、可下载 `api.md`。导出代码对话框增加同一份文档。

**验收**：对话框和导出页都能看到方法、`/api/mock/` 路径和 `data.list`。没有表格、表单、也没有任何绑定时给出提示，不改 Schema。

## 四、测试

| 项 | 测试 |
|---|---|
| 只补空地址 | 已有 URL 不变；再执行一次不新增绑定 |
| 文档 | Markdown 含方法、路径和响应示例 |
| 设计器 Mock | `/api/mock/` 且带 `example` 时不调用 `fetch`，返回 `data.list` |
| 出码 | 生成代码含该 URL，不含只存在于 `example` 里的标记 |
| 入口 | E2E：添加高端表格后点击按钮，对话框出现 `/api/mock/` 与 `data.list`，表格仍显示占位姓名 |

## 六、范围边界（本版明确不做）

- 不运行 Mock.js 服务，不生成后端业务代码，不新增后端路由去承接 `/api/mock/`。
- 不做 GraphQL、WebSocket、工作区、远程物料、管道编排、主题和国际化。
