# 低代码前端可视化平台 (Low-Code Studio) - v1.10.0 交互打磨规划

> **版本定位**：把已经能用的配置和顶栏操作磨顺，不新增组件种类
> **状态**：已实现 (Implemented)。范围与验收见下文，实现已合入 v1.10.0
> **前置版本**：v1.9.0（一键 Mock 与接口文档）
> **平台定位约束**：纯前端搭建 + 出码，**不生成后端业务代码**

---

## 一、为什么做这一版

v1.9.0 之后，表格和表单仍然靠 `config` 决定列和表单项。实际操作里有几处会打断这件事：

- 点开已生成 Mock 的组件，数据源表单会按当前输入重写 `apiBinding`，把 `example` 丢掉。下一次请求就不再返回示例。
- 请求参数还在输入、JSON 尚未写完时，参数会被写成空对象。
- 列和表单项只能增删，不能调整顺序，表单项的占位提示也不能改。
- 属性抽屉的遮罩盖住整个页面，顶栏按钮要点之前必须先关抽屉。抽屉里的尺寸、控件类型等选项仍是英文。

v1.10.0 只处理这些。不增加新的表单控件，也不做工作区、远程物料或后端代码。

---

## 二、P0 — 改数据源时留下 Mock 示例

**现状**：抽屉把绑定抄进表单，再写回节点。写回时只保留 URL、方法、参数和路径。

**方案**：

- URL 没变时，写回保留原来的 `example`。URL 清空或改成别的地址时去掉示例。
- 参数文本不是 JSON 对象时，不改已保存的参数，并在表单项下提示。

**验收**：生成 Mock 后打开该组件再点「试请求并预览」，仍然成功，表格里还有占位姓名。参数写成半截 JSON 时，已保存参数不变。

---

## 三、P0 — 配置项可以排序，占位提示可以改

**现状**：高级配置里列和表单项有添加、删除。表单项有控件类型和必填，没有占位提示，也不能上移下移。

**方案**：

- 列和表单项增加上移、下移，顺序就是画布和出码的顺序。
- 表单项增加占位提示，设计器输入框和下拉框使用这份文案。

**验收**：把第一项下移后，画布上的标签顺序跟着变。

---

## 四、P0 — 抽屉不再挡住顶栏，选项使用中文

**现状**：抽屉遮罩盖住顶栏。Element Plus 默认英文，分页和确认框、抽屉里的选项标签也是英文。

**方案**：

- 顶栏叠在抽屉之上，抽屉从顶栏下沿开始，顶栏按钮在抽屉打开时仍可点。
- 设计器套上 Element Plus 中文语言包。抽屉里的尺寸、类型、控件种类和方位选项改为中文，取值不变。

**验收**：表格还选中、抽屉仍打开时，可以直接点「生成 Mock 与接口文档」。分页文案为中文。

## 七、范围边界（本版明确不做）
