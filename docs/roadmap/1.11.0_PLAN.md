# 低代码前端可视化平台 (Low-Code Studio) - v1.11.0 出码与画布对齐规划

> **版本定位**：拖拽配置的页面，导出的 Vue 组件、Web Component 配套组件和独立 HTML 使用同一份配置
> **状态**：已实现 (Implemented)。范围与验收见下文，实现已合入 v1.11.0
> **前置版本**：v1.10.0（数据源编辑、配置排序、顶栏）
> **平台定位约束**：纯前端搭建 + 出码，**不生成后端业务代码**

---

## 一、为什么做这一版

拖入表格或表单后，画布按 `config` 和 `props` 渲染。导出却另写一套：

- 表单项占位提示在画布上可改，Vue 和 HTML 仍写死「请输入标签名」。
- 表单标签宽度、是否内联在画布上生效，出码固定 `label-width="100px"`，并且把 `labelWidth` 再写成一个无效属性。
- 表格分页大小在画布上读 `pagination.pageSize`，出码固定 10。没有行按钮时，出码仍补一列「查看」。

Vue 单文件组件、Web Component 配套的 `PageTemplate.vue` 和独立 HTML 共用同一段模板。改这一处，三条产物一起对齐。

---

## 二、P0 — 表单配置进入三种产物

**方案**：

- 占位提示用 `item.placeholder`，没有时再退回「请输入 / 请选择」加标签名。
- `required` 为真时，表单项带上必填。
- `label-width` 用 `props.labelWidth`，布局为 `inline` 时加上 `inline`，`size` 单独写出。这三个字段不再以原样属性名重复出现。

**验收**：把占位改成「请填写账号」、标签宽度改成 `140px` 后，Vue 与 HTML 都出现这两处，且没有第二个写死的 `100px`。

---

## 三、P0 — 表格分页和行按钮跟画布一致

**方案**：

- 分页大小用 `pagination.pageSize`，请求参数里的 `size` 用同一个数。`enabled` 为假时不输出分页条。
- 列上有 `align` 时写出对齐。
- `actions` 为空或不存在时不补「查看」列。有配置时按配置的文字和事件名输出。

**验收**：空操作列表的表格产物里没有「查看」按钮。分页大小为 20 时，模板和请求参数都是 20。
