## 执行计划

### M1 — P0 修复（本轮）

1. **修复 PATCH TOCTOU**：在 `storageService` 增加原子 `patchAndSave(id, ops, baseVersion)` 方法，将读-校验-应用-写全部移入写队列；controller 调用该方法。
2. **对齐 SSRF 防护**：在 `FETCH_CHECKED_SOURCE` 的 `blockedHost` 中补 `::ffff:` IPv4-mapped 处理，与 TS 版本一致。
3. **自动保存失败通知**：失败时调用 `notifyUser` 或 ElMessage 提示一次（带节流，避免刷屏）。

### M2 — P1 收口

4. **shortHash 移入 shared**：`@lowcode/shared` 导出 `shortHash`，前端 codegen/shared、materialPacker、后端 versionClassify 改为引用。
5. **收窄 `as any`**：为 `normalizeNodeIds` / `structuralSignature` 定义最小节点类型；`updateNodeLayout` 用 Grid 布局项类型。
6. **watch 优化**：拖拽/缩放手势期间跳过 stringify getter（用 `layoutGesture` 标志短路）。

### M3 — P2 测试补齐

7. jsonPatch 边界测试（根路径、非容器、add OOB、`/-`、空 ops、invert 错误）。
8. designerStore 黑盒路径测试（addBlackBoxFromMaterial / addMaterialSmart / setPageSchema / enterLayerEdit）。
9. materialController 集成测试（refs 409 / force / diff）。
10. pageUpgradeService / materialRefScan 单元测试。
11. StorageService 非保存路径测试。
