# v2.3.0 设计器手势与交互反馈规划

> **文档定位**：v2.3.0 —— 开属性手势、快捷键可见、Inspector Tab 重组、拖拽淡虚线网格、行操作友好提示。  
> **状态**：已落地 (Implemented — M1–M6)  
> **前置**：v2.2.0 已落地  
> **非目标**：物料市场 / 管道 / 协同（v3 / v4）；整页画布 zoom  

## 一句话目标

让「打开属性」好点、好记、好发现；属性栏 Tab 少而顺；拖拽时能看见但不刺眼的网格虚线；表格行操作提示像产品而不是调试日志。

## 里程碑

| 里程碑 | 内容 | 可独立合入 |
| :--- | :--- | :--- |
| **M1** | 节点条去掉「属性」、改为网格 ±；右键/双击/顶栏开属性 | 是 |
| **M2** | 常驻快捷键提示 + 顶栏可见 kbd | 是 |
| **M3** | Props+Attrs 合并；数据源 Tab 置末 | 是 |
| **M4** | 拖拽淡虚线网格可见（修层级 / 手势计时） | 是 |
| **M5** | 行操作友好兜底 + 默认 show_message + 出码对齐 | 是 |
| **M6** | 右键迷你菜单（属性/复制/删除）+ jsonPatch/原子写去重 | 是 |

## 范围决策

- 开属性：选中 ≠ 开栏；右键 / 双击 / 画布顶栏「属性」。
- 节点浮动条：类型标签 + 网格放大/缩小 + 删除。
- Inspector：属性（含 Attrs）→ Config → 事件 → 物料 → JSON → **数据源**。
- 网格：绑到可见层；淡虚线；拖/缩显示；去掉 50ms 误关手势。
