# 低代码前端可视化平台 (Low-Code Studio) - v1.8.0 核心闭环收尾规划

> **版本定位**：把已经有的搭建、保存和预览补到能独立用完，不新增产品形态
> **状态**：已实现 (Implemented)。范围与验收见下文，实现已合入 v1.8.0
> **前置版本**：v1.7.0（必填拦截、显隐表达式、动作条件、页面状态）
> **平台定位约束**：纯前端搭建 + 出码，**不生成后端代码**

---

## 一、为什么做这一版

v1.7.0 之后，拖拽、出码、表单提交和条件显隐已经能工作。日常闭环里还缺三处已经开口、但没做完的细节：

- 页面标题不能改。加载列表能载入，不能删除。备份接口已经能恢复上一份，设计器里没有入口。
- 「纯预览模式」只藏起左右面板，画布上的拖拽手柄和删除按钮还在，预览时仍会选中组件。
- 表单下拉框在画布和出码里会渲染选项，属性抽屉不能增删选项，选成 Select 之后没有可编辑的选项。

v1.8.0 只补这三处。工作区、远程物料、协同、主题、国际化和 Mock 仍不做。

---

## 二、P0 — 已保存页面可以改名、载入、删除、恢复

**现状**：画布标题是纯文本。加载对话框把列表里的对象直接塞进设计器，没有删除按钮。`POST /api/schemas/:id/restore` 已存在，请求体文档写的是 `index`，控制器只读 `backup`。

**方案**：

- 非预览时，画布标题改为输入框，写入 `pageSchema.title`。
- 载入改为 `GET /api/schemas/:id`，用返回的完整 Schema 调用 `setPageSchema`。
- 删除调用已有的 `DELETE /api/schemas/:id`，先确认，成功后从列表移除。
- 恢复上一份读取备份列表，取最新一代（index 最小的 `.bak.1`），调用恢复接口，再把返回的 Schema 载入设计器。没有备份时提示，不改当前画布。
- 恢复接口同时接受 `index` 和 `backup`，响应 `data` 为恢复后的 Schema。

**验收**：改标题后保存，再次载入标题仍是新的。删除后列表不再出现该 id。连续保存两次后，恢复上一份使画布回到上一份内容。

## 三、P0 — 纯预览不再露出搭建控件

**现状**：`isPreviewMode` 只隐藏物料面板和属性抽屉。网格仍可拖拽、缩放，节点工具条和删除按钮仍在，点击仍会选中。

**方案**：

- 预览时网格 `is-draggable` 与 `is-resizable` 为假，隐藏节点工具条和删除按钮，点击不选中、不打开抽屉。
- 组件本身的按钮、表单提交和显隐保持可操作。视口切换保留。
- 退出预览后拖拽和删除恢复。

**验收**：进入纯预览后看不到删除按钮，按钮点击仍能执行动作链。退出后删除按钮回到画布。

---

## 四、P0 — 下拉选项可编辑

**现状**：`pro-form` 的 Select 在设计器和出码里读取 `item.options`。抽屉里只能改标签、字段名、控件类型和必填，不能改选项。

**方案**：

- 控件类型为 `select` 时，在该项下编辑选项的显示文字和值，可添加、删除。
- 从其它类型改成 `select` 且还没有选项时，放入两条默认选项。
- 设计器下拉框和出码里的 `el-option` 使用同一份 `options`。

**验收**：把选项改成「男 / male」后，设计器下拉和导出模板都出现该文字和值。没有选项的 Select 不会在模板里写出空循环以外的写死选项。

## 六、实施顺序

| 阶段 | 内容 | 完成标准 |
|---|---|---|
| 1 | 改名、载入、删除、恢复 | 设计器能完成一次保存、删除、恢复 |
| 2 | 预览与下拉选项 | E2E 与出码单测通过 |
| 3 | 全仓 version 改为 `1.8.0` | `npm run typecheck`、`npm run lint`、`npm test` 通过；README changelog 写上 v1.8.0 |

版本号只在阶段 3 修改。规划合入时不改运行时版本。

## 七、范围边界（本版明确不做）

- 不做多工作区、多项目目录隔离。
- 不做远程物料、节点式流程图、管道编排、主题、国际化、Mock。
- 不新增独立的 `/preview/:pageId` 站点；预览仍是设计器里的纯预览模式。
- 不生成后端代码，不引入 RBAC / SSO。
