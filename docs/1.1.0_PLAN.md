# 低代码前端可视化平台 (Low-Code Studio) - v1.1.0 体验增强版规划

> **版本定位**：画布辅助交互、精度微调与日志 Diff 增强版 (UX & Precision Enhancements)
> **状态**：进行中 (In Progress)
> **前置版本**：v1.0.0 (基础 GA 正式版)

---

## 🎯 1.1.0 核心目标

基于 v1.0.0 正式版的稳固基础，v1.1.0 专注于提升画布设计器的**极致操作手感**与**运维感知体验**，包含以下三大增强特性：

1. **画布对齐参考线与吸附指示 (Canvas Alignment Guides & Snapping)**：在组件拖拽与调整大小时显示水平/垂直中心与边缘吸附线。
2. **键盘精度微调 (Keyboard Arrow Fine-Tuning)**：选中画布组件时，按方向键以 1px / 1 栅格平移或微调。
3. **操作日志 Schema 可视化 JSON Diff (Audit Log Visual JSON Diff)**：在审计日志中，清晰展示 Schema 历史对比差异（新增/修改/删除属性高亮）。

---

## 📋 详细功能设计

### 1. 画布对齐参考线 (`CanvasGrid.vue` & `SnappingGuides.vue`)
- 在拖拽调整节点时计算同层级其他节点的 X/Y 坐标，相近时显示红/蓝虚线标尺。

### 2. 键盘方向键微调 (`useKeyboardShortcuts.ts`)
- 当选中组件且焦点在画布时，`ArrowUp` / `ArrowDown` / `ArrowLeft` / `ArrowRight` 调整组件的 `x` / `y` 或 `w` / `h`（按 `Shift` 时以大步长微调）。

### 3. 操作日志 JSON Diff (`AuditLogDialog.vue` / `jsonDiff.ts`)
- 在 SQLite 审计日志弹窗中增加“查看改动 Diff”模式，结构化高亮与前一版本的字段改动对比。
