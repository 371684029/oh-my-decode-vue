> **版本定位**：基础功能完备、生产可用、稳定易用的 1.0.0 正式版 (General Availability Base)
> **状态**：规划中 (Drafting)
> **演进路线**：v0.0.1 (基础平台) -> v0.2.0 (自动保存/出码) -> v0.3.0 (响应式/表达式) -> v0.5.0 (工作区/I/O强校验) -> **v1.0.0 (基础正式版 Base GA)** -> v3.0.0 (远期企级架构)

## 🎯 1.0.0 基础正式版核心目标

经过 v0.0.1 至 v0.5.0 的快速迭代与规范沉淀，v1.0.0 聚焦于**基础功能的稳固性、易用性与完备性**。不追求过早引入复杂的分布式/RBAC/CRDT等超大厂架构，而是确保**拖拽搭建、物料渲染、配置存取、零废码出码、页面发布与日志追溯**这套核心链路达到 100% 生产可用标准。

---

## 📋 1.0.0 基础核心功能清单

### 1. 稳固的拖拽可视化搭建与网格布局 (Robust Visual Drag-and-Drop)
- **流畅的拖拉拽**：基于 `vue3-grid-layout-next` 实现元素拖投放置、自由调整宽高与自动排版。
- **全方位画布操作控制**：支持节点选中、多选、复制 (`Ctrl+C`)、粘贴 (`Ctrl+V`)、删除 (`Delete`)，以及 30 步高可靠撤销/重做历史栈 (`Ctrl+Z` / `Ctrl+Y`)。
- **多端响应式视图适配**：支持桌面 (100%)、笔记本 (1366px)、平板 (768px) 及移动端 (375px) 一键快速预览。

### 2. 标准化组件物料库与属性抽屉 (Material Registry & Property Inspector)
- **丰富的内置物料**：包含 `ProTable`（高端表格）、`ProForm`（高端表单）、`ProContainer`（嵌套弹性容器）以及 Element Plus 基础 UI 组件（按钮、输入框、卡片、标签、开关等）。
- **组件 I/O 契约强校验**：基于 `docs/COMPONENT_IO_SPECIFICATION.md`，在属性抽屉中对必填入参 (Inputs/Props) 进行实时校验提醒，防止空参导致渲染崩溃。
- **动态 JavaScript 表达式支持**：属性面板支持绑定 `{{ ... }}` 表达式，实现跨组件数据联动。

### 3. 高靠的 JSON 存储与可视化操作审计 (Storage & Audit Logging)
- **JSON 文件直接持久化**：页面/组件 Schema 直存为本地干净的 `.json` 配置文件，原生适配 Git 版本追踪。
- **静默 3 分钟自动保存**：后台无感保存，带有淡雅的右下角指示器，保障断电/崩溃不丢配置。
- **简易可视化操作日志控制台**：基于 SQLite (`logs.db`) 提供日志弹窗/列表面板，支持按时间、操作人、页面筛选并展开改动 JSON 摘要。

### 4. 零废码多目标出码与基础页面发布 (Multi-Target Export & Basic Publish)
- **多目标出码引擎**：一键生成标准 Vue 3 SFC (`.vue`)、W3C 原生 Web Component (`.js`) 及单页独立静态 Bundle (`.html`)。
- **基础页面发布与预览 (Basic Page Publishing)**：提供简易的在线页面发布功能，支持生成可直接访问的预览链接或下载生产 Ready 产物。

## 💡 1.0.0 基础版落地方案建议 (Practical Advice for Base GA)

1. **全面聚焦开箱即用 (Out-of-the-Box Experience)**：
   - 保持架构简洁明了，采用 Node.js + Express + SQLite + 本地 JSON 存储，免去部署复杂外部数据库（如 PostgreSQL/Redis）的成本。
2. **注重边界条件处理与容错 (Robust Error Handling)**：
   - 对画布渲染组件加装 Vue `onErrorCaptured` 错误边界防护，确保某单组件报错时不会导致整页白屏。
3. **保持极致的代码与文档工整性**：
   - 遵从单职责原则 (SRP) 与严格的 TypeScript 类型标记，保持各模块完全解耦，为将来的 v3.0.0 架构升级打下坚实基础。
