## 📋 3.0.0 核心高级功能规划

### 1. 企业级 RBAC 权限体系与 SSO 单点登录 (Enterprise RBAC & SSO)
- **多租户权限模型**：租户 (Tenant) -> 工作区 (Workspace) -> 项目 (Project) -> 页面/物料粒度的细粒度权限控制。
- **角色权限控制 (RBAC)**：支持系统管理员、工作区管理员、低代码开发者、访客/预览者四种角色，精细控制“新建/编辑/发布/导出代码/查看审计日志”权限。
- **企业 SSO 单点登录对接**：集成 OAuth2 / OIDC / SAML 协议，支持一键接入企业钉钉、飞书、企微、自建 LDAP 或 Keycloak 统一身份认证。

### 2. 高可用分布式数据与文件持久化引擎 (High-Availability Storage Engine)
- **高可用关系型数据库**：从本地 SQLite 迁移至 PostgreSQL / MySQL 数据库集群，支持主从复制与事务读写分离。
- **分布式对象存储 (Object Storage)**：JSON Schema 历史快照、图片资源与出码产物自动同步至 AWS S3 / 阿里云 OSS / 腾讯云 COS。
- **分布式缓存中枢**：引入 Redis 集群处理热点 Schema 缓存、自动保存草稿及协同锁。

### 3. 多人实时协同编辑与冲突解决机制 (Real-time Collaboration & CRDT)
- **基于 CRDT 算法**：采用 **Yjs / Automerge** 协同框架，基于 WebSocket 实时同步画布节点改动。
- **协同指针与感知 (Presence)**：实时展示同项目内其他协同者的光标位置、正在选中的组件节点及当前编辑属性。
- **细粒度节点锁 (Node Locking)**：被他人选中的组件自动呈现亮色防护框，防止多人并发修改同一节点属性造成配置覆盖。

### 4. 自动化 CI/CD 发布流水线与一键部署 (Automated Release & CI/CD Pipeline)
- **页面一键发布 (One-Click Publish)**：低代码页面无需人工重新打包，自动触发云端 Webhook，将其编译发布至线上 CDN 或内网 K8s Pod 节点。
- **灰度发布与 Canary 流量切分**：支持按用户 Cookie、IP 比例（如 10% 灰度）分配新版低代码页面流量。

### 5. 专业 Pro-Code 扩展生态与 IDE 插件 (VS Code Extension & Pro-Code IDE)
- **VS Code 低代码本地插件**：提供官方 VS Code 扩展，允许前端工程师直接在 IDE 中双向同步低代码 Schema 与本地 `.vue` 代码。
- **自定义物料一键 CLI 工具链 (`@lowcode/cli`)**：提供命令行交互脚手架，支持 `lowcode init-material` / `lowcode publish` 一键构建并发布公司私有 UI 组件库入低代码物料市场。
